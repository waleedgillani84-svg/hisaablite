# Hisaab lite hisaab management  (Progressive Web App)

Offline-capable PWA ready for **GitHub Pages** deployment.

## 🚀 How to Deploy on GitHub Pages

1. **Create Repository:** Create a new repository on GitHub (e.g., `hisaab lite`).
2. **Upload Files:** Upload all generated files (`index.html`, `manifest.json`, `sw.js`, `README.md`, `icon-192.png`, `icon-512.png`) to the root.
3. **Enable GitHub Pages:** Go to **Settings** -> **Pages**, choose **Deploy from a branch** (`main` / `root`).
4. **Access App:** Link will be live at: `https://<username>.github.io/<repo>/`
